Политика конфиденциальности

Приложение «Дневник самочувствия» (Android). Обновлено: 2026-08-02.

Записи о головной боли и давлении остаются только на устройстве пользователя.

  • Данные дневника не передаются на сервер разработчика.
  • Копия CSV создаётся, только когда пользователь сам сохраняет её через системное окно выбора файла Android.
  • Отчёт PDF создаётся только по команде пользователя и передаётся через системное меню «Поделиться».
  • Сохранённая копия CSV и отправленная копия PDF находятся вне хранилища приложения и не защищены пин-кодом дневника. Пользователь сам выбирает надёжное место и получателя, которому доверяет.
  • Для входа можно поставить пин-код, а при желании ещё и отпечаток.
  • Сообщение разработчику отправляется через почтовый клиент пользователя.
  • Данные не продаются и не передаются рекламным сервисам.

Приложение не ставит диагнозов и не заменяет консультацию врача.

Privacy notice (EN)

App “Health diary” (Android). Updated: 2026-08-02.

Headache and blood pressure entries stay on the user’s device only.

  • Diary entries are not sent to the developer’s server.
  • A CSV backup is created only when the user saves it through Android’s system file picker.
  • A PDF report is created only when the user asks and is passed to Android’s system share menu.
  • A saved CSV backup and any shared PDF copy are outside the app’s storage and are not protected by the diary PIN. The user chooses a safe location and only recipients they trust.
  • The diary can use a PIN to open and, if the user likes, add fingerprint unlock.
  • Developer contact uses the user’s email app.
  • Data is not sold or shared with advertisers.

This app does not diagnose conditions and is not a substitute for medical advice.
